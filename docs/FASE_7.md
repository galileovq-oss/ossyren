# Fase 7 — Progresión y loot (plan, aún sin construir)

Salida: dos configuraciones de personaje viables. Tag: `v0.7-progression-loot`.

## Decisiones ya tomadas
- **Cuatro atributos:** Strength, **Agility** (evasión + precisión + movilidad), Vitality, Tech. Ninguno obligatorio para que una clase funcione; afinidades, no restricciones.
- **Muerte estilo Diablo:** reaparecer en el hub y perder algo menor (oro o durabilidad). Llega con el hub.
- Ritmo base −15 % y **techos de velocidad** (movimiento y AS/CS) que se deciden aquí, con el equipo.
- Pociones: 5 cargas, drops + hub, mejora tipo Estus. Mana clásico + cooldowns cortos.

## Alcance propuesto
- XP, niveles, puntos de atributo y de talento, requisitos de nivel.
- Árbol de talentos compacto por clase (activas + pasivas, rangos), respec limitado placeholder.
- Slots de equipo, calidades (normal / mágico / raro / único), affixes, 1–2 únicos de prueba con mecánica propia.
- Dos sets de armas persistentes y guardado/carga inicial.
- XP repartida entre encuentros, objetivos, descubrimientos y cofres (no solo matar).

## Preguntas abiertas para cuando arranquemos
- Moneda y qué se pierde al morir; durabilidad sí/no.
- Techos de velocidad de movimiento y AS/CS por equipo y talentos.
- Cuántos puntos de talento por nivel y los 3 side-quests garantizados.
